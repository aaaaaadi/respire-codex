# 记忆中文可见提示方案

用户已确认直接实现简短的召回、实际采用和上轮保存提示；安装测试、中文提交并推送 Fork，官方 PR 等用户确认。

## 选择与边界

采用钩子附加上下文引导前台输出普通中文状态文字，并将钩子的处理中状态改为中文。原生 MCP 工具卡片由 Codex 界面渲染，恢复这类卡片需要改变工具接入方式，本次不引入第二套记忆入口，也不把系统警告冒充工具调用。

## 显示规则

- 开头一行，例如“记忆：召回 4 条候选；上轮记忆：已保存并回读确认”。数量只计算实际传给模型的安全候选；空结果、暂停、错误和主动跳过分别提示。
- 读取正文且实际用于回答后，前台简写“已参考记忆：〈标题〉”，最多两条。未采用则最终简写“记忆：本次未采用”。此状态依赖模型对本次回答的判断，插件不会把召回或读取直接判成采用。
- 上轮存储依据会话状态：只有非空有效写入 ID 全部出现在回读确认列表中才显示确认成功；仅收到写入回执、尚在整理、结果未确认、无新增、已存在分别显示。
- 同一结果只提供一次提示；较早回合稍晚完成时明确标“较早回合”。升级不逐条播报历史记录；不跨会话搬运结果。提示交给模型不等于界面送达确认，重复事件仍沿用防重保护。
- 不等待后台、不重试不确定写入、不在状态文件存储标题或正文；只增加提示资格与结果摘要元数据。

先运行失败测试，再实现状态分支和去重；运行完整测试、语法和打包校验。通过正式本地市场安装 0.2.3-local.2，保留 local.1 回退包。使用真实引擎和受限模型验证提示，区分受控验证与桌面自然显示；不制造测试记忆，不改信任、不重启用户客户端。
