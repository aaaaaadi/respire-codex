# 简短英文记忆提示方案

用户确认按“候选数量＋实际采用短 ID”显示；没有上轮保存回执就省略。安装测试后使用中文提交并推送 Fork，官方 PR 等用户确认。

## 显示规则

- 首条可见回复单独一行输出英文短标签，例如 Memory: 5 found · Last save: verified，不翻译、不扩写、不混入正文。
- 成功读取正文且实际用于回答后，输出 Used: 加真实 ID 前 8 位；多条用逗号分隔。已知前缀有歧义时延长至可区分，不编造 ID。默认不显示标题、正文或完整 ID；用户询问依据时再展开。
- 未采用时显示 Memory: unused。空召回为 Memory: no match；跳过与不可用分别为 skipped 和 unavailable。
- 上轮确认回读为 Last save: verified；正在处理为 pending；仅有写入回执为 unverified；结果未确认是 unconfirmed；无新增为 not needed；已有记录为 already exists；只读为 read-only。
- 上轮既没有归档状态，也没有明确写入回执时不显示保存标签。较早回合迟到结果使用 Earlier save，避免误认为上轮。
- 保留既有状态去重值，仅翻译显示文案，避免升级重播旧通知。无回执的记录仍可在后台完成后补报。
- 实际采用由模型基于正文读取与回答使用情况判断，不能由候选命中自动推断。提示交给模型不等于桌面送达确认。
- 不新增 MCP，不改信任，不重启客户端；不是原生 MCP 工具卡片。

## 验证与交付

测试覆盖有效候选计数、保存回执与回读、延迟结果、无回执省略、旧状态去重和会话隔离。使用安装后的真实引擎与受限模型检查英文提示、短 ID 和默认无标题，不写测试记忆。安装 0.2.3-local.3，保留 local.2 回退。

实际验收：40 项测试与已安装包离线用例通过。本轮真实模型复验被自动审批拒绝，未发送私有记忆正文；实际模型采用和桌面显示仍待确认。
